Importer des relevés

1. Les comptes (fichiers CSV)

Sélectionnez en une fois tous les fichiers exportés depuis Bank Perfect. Chaque fichier devient un compte nommé d'après le fichier. Réimporter un fichier ne crée pas de doublons.

2. L'échéancier (Echeances.bpsched)

Importez-le après les comptes : les catégories sont retrouvées dans votre historique.

3. Revolut (relevé CSV)

Dans l'app Revolut : Compte, puis Relevé, format Excel/CSV. Les opérations arrivent pointées, sans doublons même si les périodes se chevauchent. La catégorie est reprise quand le commerçant est déjà connu ; le reste se range avec « Classer ».
